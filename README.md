A one-line entry for the "The Dog Reviews the Mailman" bounty: one funny one-line review a dog gives the mailman. The dog leaves a one-star review — the mailman shows up every day smelling of every dog on the street, then leaves without letting the dog sniff his bag. The program validates the line (at most 200 characters, ASCII, single line) and writes it to `entry.txt`.

## Run it

```sh
python3 main.py
```
